# git-training

Repositorio para capacitación de Git.

## Contenido

- [`git-history.md`](./git-history.md): lectura breve (2-3 min) sobre qué es Git, por qué Linus Torvalds lo creó tras el conflicto con BitKeeper en 2005, y qué problema resuelve. Incluye foto de Linus Torvalds en `images/`.
- [`git-navigation.md`](./git-navigation.md): cómo navegar un repositorio en GitHub a través de sus secciones Code, Branches, Commits y Pull Requests, con links directos a este repo.

## Propósito

Este repositorio se usará para practicar flujos de trabajo con Git: commits, ramas, merges, etc. El historial de commits se irá construyendo paso a paso como material de referencia para la capacitación.
