# Navegando un repositorio en GitHub

Cuando entras a un repositorio en GitHub, hay cuatro secciones clave para orientarte rápido:

- **Code**: el contenido actual del repositorio (archivos y carpetas) en la rama seleccionada.
  👉 https://github.com/Camilo-Barros-BA/git-training

- **Branches**: todas las ramas existentes, cuáles están activas y cuántos commits de diferencia tienen entre sí.
  👉 https://github.com/Camilo-Barros-BA/git-training/branches

- **Commits (historial / sources)**: la línea de tiempo de cambios, con cada commit, su autor y su mensaje.
  👉 https://github.com/Camilo-Barros-BA/git-training/commits/main

- **Pull Requests (PR)**: las propuestas de cambio entre ramas, donde se revisa y discute el código antes de fusionarlo.
  👉 https://github.com/Camilo-Barros-BA/git-training/pulls

Explorar estas cuatro vistas es la forma más rápida de entender el estado y la historia de cualquier repositorio.
